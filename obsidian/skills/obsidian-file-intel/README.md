# obsidian-file-intel

## Quick start

Process a folder of documents into Obsidian-ready summaries.

Example request: “Summarize the PDFs and spreadsheets in this folder.”

Requires a compatible external `scripts/process_files_with_gemini.py` and Gemini credentials. The processor is not bundled. Results go to `outputs/file_summaries/YYYY-MM-DD/`.

# obsidian-headless

## Quick start

Sync and publish an Obsidian vault from the command line with Obsidian Headless (`ob`), without the desktop app.

Example request: “Set up Obsidian Sync for my vault on this server.”

Requires the Obsidian Headless CLI (`ob`) and an Obsidian Sync or Publish subscription for the feature you use.

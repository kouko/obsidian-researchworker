# obsidian-research

## Quick start

Research a question and save one readable, source-linked note.

Example request: “Research this topic and write an Obsidian note.”

One note in the selected vault’s `research/` folder, with a conclusion, contents and citations. For saved work across rounds, see [obsidian-research-project](../obsidian-research-project/README.md).

Select an Obsidian vault containing `.obsidian/`. For web research, the current session needs a web search tool. If the tool is unavailable and you supplied sources, the skill can continue using those sources and records the limitation in the reply and the note. For a local-only request, it uses only the supplied material.

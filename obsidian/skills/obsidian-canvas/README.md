# Obsidian Canvas

**English** | [日本語](README.ja.md) | [繁體中文](README.zh-TW.md)

Create Obsidian Canvas files from text content, supporting both MindMap and freeform layouts, plus four community patterns (kanban, dashboard / home page, research map, moodboard) with templates and an output validator (`scripts/validate_canvas.py`), and a zero-plugin advanced patterns reference (nested canvas workspace, research dual-canvas, data-pipeline documentation, audit / post-mortem / onboarding canvases, teacher class canvas, worldbuilding, Bases-in-canvas 1.9+, canvas-only / 2D MOC) with a nested-workspace template.

## Quick start

Arrange notes, cards and relationships in an editable Obsidian Canvas.

Example request: “Make a research map from these notes.”

A `.canvas` file. Choose a mind map, freeform layout or a bundled pattern and validate the result.

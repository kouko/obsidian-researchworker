## Scope and evidence status

Agent-decided, 2026-11-16: use 21 fiscal years (84 expected quarters) rather than
the preliminary FY2007–FY2026 inventory. This avoids a literal twenty-calendar-
year boundary ambiguity without dropping any originally required research.
The first issuer release explicitly identifies FY2006 Q1 ending 2005-12-31;
the latest annual header identifies FY2026 ending 2026-09-26. Quarter identity
must still be checked against each original filing; calendar months are not a
substitute. This selection does not establish a publication cutoff for all years.

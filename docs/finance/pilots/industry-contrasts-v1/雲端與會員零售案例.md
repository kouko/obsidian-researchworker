# Microsoft 與 Costco 方法對照

這兩個案例檢查成長率、現金投入與獲利歸屬是否被錯誤混用；並非完整估值或已驗證的投資建議。

## Microsoft 2024Q4：成長與資本投入分開

公司財季結束 2024-06-30，資訊截止為 2024-07-30 紐約時間日終。原始公告列季營收 64,727、營業現金流 37,195、現金購置不動產與設備 13,873 百萬美元。後者約占營收 **21.43%**；簡單 CFO 減現金設備支出為 **23,322 百萬美元**，是本地現金流代理值，不代表可分配現金，也未涵蓋所有租賃與承諾。Azure 與其他雲端服務收入增長 29%，固定匯率口徑為 30%；不可混成單一成長數。[原始季度公告與現金流表](https://www.microsoft.com/en-us/Investor/earnings/FY-2024-q4/press-release-webcast)

拒絕以「Microsoft Cloud 總收入」直接視為 Azure 單獨收入，也不將現金設備支出全稱為 AI 投資；原始總額不足以做這種歸因。研究應分開已實現收入、合約／遞延收入、現金與非現金投入、未來折舊及產能利用。短期看收入與預期差；中期看投入轉為收入與折舊壓力；長期看可持續報酬與競爭。缺訂單轉換、細部投入、同日價格與估值情境，三個期限皆不產生買賣評級。

這裡保留當期公告的分部口徑。未核對之後的組織或分部重編前，不將不同版本的分部收入接成一條可比時間序列；也不使用後來的 AI 成果證明此時的投資必然成功。

## Costco 2024Q3：會員費不是已分配利潤

公司財季為截至 2024-05-12 的 **12 週**，資訊截止為 2024-05-30 紐約時間日終。原始申報附件列淨銷售 57,392、會員費 1,123、總收入 58,515、營業利益 2,197、淨利 1,681 百萬美元。會員費／營業利益約 **51.12%**，但沒有成本分攤資料，不能宣稱會員費貢獻了這個比例的利潤；總收入營業利益率約 **3.75%**。[原始申報附件](https://www.sec.gov/Archives/edgar/data/909832/000090983224000026/costex9918-k51224.htm)

EPS 3.78 對前期 2.93 的增長約 **29.01%**；公告指出前期含一次性費用每股 0.50 美元，若僅以此作本地調整，3.78／(2.93＋0.50)−1 約為 **10.20%**。後者使用四捨五入 EPS，並非公司完整調整後獲利或預測。公告亦指出前一年 53 週造成財曆移動，當季淨銷售受到約 0.5–1.0% 正向影響；同店銷售另按可比週數呈現。

拒絕直接將 12 週季報乘四當作全年，或將會員費收入視為全數自由現金流。短期需同店銷售、客流與一次性基期；中期需續約、會費認列與展店經濟；長期需會員價值與再投資報酬。未取得當期續約／現金收費明細、股價與估值，三期限都保留證據不足；不以後來會費調整或股價表現回填本次分析。

## 尚待驗證

兩案例仍需原始完整季度申報、競爭與估值證據及獨立研究審查。這些對照支持產業方法分流，不證明完整產業覆蓋、跨期績效或投資能力。

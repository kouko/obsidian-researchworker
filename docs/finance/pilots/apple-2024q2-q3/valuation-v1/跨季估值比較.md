# AAPL 2024Q2 至 2024Q3 估值補充比較

在相同的五年假設下，Q3 評估日需要更高的獲利成長，才能抵銷較高的買入價格。這不證明 Q3 價格錯誤；市場可能已反映本試點尚未量化的未來機會。

| 可核對項目 | Q2：2024-05-03 | Q3：2024-08-02 |
|---|---|---|
| 收盤價（USD） | 183.38 | 219.86 |
| 滾動淨利（USD billion） | 100.389 | 101.956 |
| 市值代理值／滾動淨利 | 28.01 倍 | 32.79 倍 |
| 假設第五年 25 倍、年化價格報酬要求 8%，所需淨利年成長 | 10.48% | 14.02% |

兩評估日收盤價相差 19.89%；滾動淨利相差 1.56%。這是已知觀測值的描述，不是先前策略的已實現績效，也未調整股利。由於股數日期不同，倍數變化同時包含價格、淨利和股數代理值的影響。

[Q2 補充](2024Q2-估值補充.md)只使用 Q2 截止日前的財務資訊；[Q3 補充](2024Q3-估值補充.md)另建計算，沒有把 Q3 新資訊回填成 Q2 已知。原先兩期綜合分析仍是歷史版本。

兩期都維持證據不足評級。下一個實質缺口是把假設接回營運證據：產品／地區／服務營收、利潤率、回購和稀釋，再以當時可取得的同業與市場預期檢查倍數。尚未完成二十年回溯、多產業驗證、現金流估值或自動更新技能。

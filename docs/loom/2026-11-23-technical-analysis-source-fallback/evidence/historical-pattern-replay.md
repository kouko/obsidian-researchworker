# Replay against independently described historical formations

Implementation under test: `0363964`. The research harness in `/private/tmp/chart-pattern-pilot-20261123/candidate-reference.py` feeds rolling daily prefixes of at most 250 rows through the same swing and pattern functions used by the report. Unadjusted Yahoo Finance daily downloads are in `*-reference.csv` in that directory. Run `env/bin/python candidate-reference.py` there. The captured output is `candidate-reference-final.jsonl`.

The reference label is the linked publisher's example. A same-type label counts as agreement only when the major anchor and break chronology support the same formation. The following deliberately avoids treating all same-type labels as matches. Source dates refer to the formation on the chart. The daily data versions were downloaded later and this offline rule check does not establish their historical availability.

The controlled verification matrix tests all eight types and cutoff/lifecycle behavior. The external cases show that reproducing those exact human-annotated shapes is a distinct unresolved reliability question. The implementation evaluates bounded local swing formations and does not promise to reproduce every broad interpretation. No predictive outcome was measured.

## 對你既有的資料做了什麼

測試只在臨時筆記庫按測試指令新增報告、圖表和行情附件。既有個人筆記和設定未受影響。

## 代你做的決定

- 各期共用一份具備來源、調整方式與截止時間的快照，方便用相同資料重算。
- 用快照可取得的時間判定歷史資料是否合格，依照實際擷取或驗證結果說明失敗原因。
- 按波段轉折點所需日線的發布時間判定何時能辨識形態，未提供單日發布時間時依交易時段收盤推算，再用日收盤與邊界判定確認或失效。
- 用固定規則與獨立歷史案例交叉檢查。數個實際案例未重現來源圖表的日期或價位，這次沒有量測辨識準確率或預測成效。

# 移除手寫研究筆記的雜湊檢查
originator: kouko
kind: product
needs-design: yes — 調整筆記編輯後的研究沿用與續存行為，且需處理既有紀錄
status: confirmed 2026-11-21
intent_confirmed_sha: b84fa26

## Problem

季度分析引用手寫筆記後，修正錯字或排版也可能使分析被列為待復驗。存檔時，手寫筆記的更動也可能被回報為存檔衝突，讓日常編輯增加不必要的續存阻礙。

## Proposed outcome

使用者可自由編輯一般研究筆記。是否重做分析，由 agent 根據被引用的主張及原始證據判斷。續存時只因實際影響新存檔的衝突而停下。

## Acceptance

1. 編輯普通研究筆記時，拼字、排版或其他不影響研究主張的修改不會自動使既有分析待復驗，也不會單憑檔案內容不同而拒絕續存。
2. 被引用的主張移除、改變或缺乏合格的當期原始證據時，agent 能指出受影響的分析，並保留其他可沿用的結果。
3. 新研究紀錄不要求保存普通筆記的雜湊。既有含雜湊的研究紀錄仍可讀取與接續，毋須修改既有檔案。
4. 真正的同時存檔衝突仍會被辨識。單季搬移後仍可核對此前引用的 SEC 原件與歷史截止。

## Constraints

- 移除範圍為普通手寫研究筆記的雜湊，包括採用時的逐檔判定，以及普通筆記編輯帶來的存檔衝突判定。
- 維持季度接續及開放研究資料的既有約定。手寫筆記是研究線索，採用其主張仍須對照適用期間、可用日期和原件。

## Value case

使用者可在持續使用 Obsidian 編輯研究資料的同時接續季度分析。現行做法仰賴改動後重新驗證甚至重試存檔。GO — 優先去除一般筆記帶來的重工，採用判斷仍以實際研究證據為準。

## Out of scope

- SEC 擷取與原件完整性檢查、正式季度紀錄的寫入保護、既有資料遷移、替換正式流程為純文字試跑版。
- 推送、建立或合併 PR。

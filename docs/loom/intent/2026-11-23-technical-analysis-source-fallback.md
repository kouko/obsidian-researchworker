## Problem

使用者在新對話請求美股技術分析時，即使助理選用了技能，仍可能在行情下載受阻時改用多處網頁的價格與均線。測試中，使用相同股票與最近已收盤交易日，對話與技能報告得出不同的短、中期判斷，使用者難以辨認差異來自行情、截止時間還是分析方法。

## Proposed outcome

每份技術分析都能追溯至同一份合格行情快照，包含可從價量資料重算的圖表形態分析。完成實算後，使用者也能閱讀有來源的第三方觀點，並清楚辨別每段內容的依據。可用資料不足時，使用者能看出原因及哪些期間缺乏判斷依據。

## Acceptance

1. 行情取得成功時，短、中、長期的數值、日期與判斷可由報告所依據的同一份行情快照重算。
2. 即時行情不可取得時，有合格本機快照仍能完成其資料所支持的分析，並清楚標示採用的資料版本與截止時間。
3. 無合格快照時，回覆交代可查證的失敗原因，保留短、中、長期並標示資料不足，沒有以零散行情或外部均線補出判斷。
4. 完成實算並找到可查證的外部技術觀點時，回覆在實算結果之後另列觀點、來源與適用日期或期間。外部觀點不改寫實算的數值、方向、改判條件，也不填補資料缺口。
5. 短、中、長期的雙重頂底、頭肩頂底、箱型，以及上升、下降與對稱三角形，可由各期的已收盤價量重算。識別到形態時列出關鍵日期、價位與確認或失效條件；未識別到形態或資料不足時，能區分兩種結果。

## Constraints

- 維持單一美股及已收盤日線的適用範圍，歷史請求遵守原有的資料可用時間限制。
- 歷史分析附列的外部觀點須能核實在指定截止時間前已公開。
- 依專案原則保護既有筆記與設定。依賴安裝限隔離環境。

## Value case

- 受益者是用一般問句請求美股技術分析、並要核對報告來源的使用者。
- 即時對話兩次重現，優先處理會影響日常使用的來源一致性。
- 現有替代方式是在隔離環境直接執行腳本或提供本機快照，需要使用者準備資料或環境。
- 外部觀點原本須另外搜尋與對照，附列後可直接看出第三方採用的時間尺度或判斷差異。
- GO — 先投入可重現的即時行情與資料不足流程，假日週判定與其他發現另行處理。

## Out of scope

- 假日週與既有長期趨勢判定、其他市場、技能選用範圍、價位格式、額外輸入格式及既有筆記遷移。
- 三重頂底、楔形、旗形、三角旗與 K 線形態。

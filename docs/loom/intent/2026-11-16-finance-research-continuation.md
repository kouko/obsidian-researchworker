## Problem

kouko 希望投資研究能跨多次對話持續累積。目前雖有已保存的季度筆記與
只讀判斷工具，仍須先由人或 agent 手動整理輸入、指出未完成工作，再自行
撰寫研究。只看檔案修改時間又無法可靠分辨新資訊、未完成分析與單純排版
變動，因此尚不能從既有資料夾直接接續必要研究。

## Proposed outcome

agent 在指定的投資研究資料夾中辨認需要的新季分析、既有分析更新與未完成
工作，接續必要研究並留下可查驗的來源、版本、缺口與完成狀態；沒有必要
更新時，保留既有結果並說明。使用者不必逐份指定待更新筆記或手動建立季度。

## Acceptance

1. 指定研究資料夾中的標的、既有季度、完成狀態及待辦可被辨認，不依賴本次對話或預先手填的工作清單。
2. 新披露季度、既有季度相關證據變更及中斷工作能導致相應的研究接續，已完成且仍適用的分析可被重用。
3. 沒有新相關證據或只有格式與修改時間變動時，不會產生重複季度或無根據的新投資建議。
4. 新分析保留原始來源、資訊截止時間、條件假設、短中長期判斷及證據不足的結論，歷史版本與跨季差異可追查。
5. 來源無法查新、資料缺失、使用者編輯衝突或執行中斷時，既有筆記受到保護，不會錯報完成或最新。
6. 在隔離筆記庫的實際宿主新 session 中，可重現新季、更新、接續及無待辦的結果，並驗證增量更新與復原。

## Constraints

- 沿用已確認的公司財季、資料發佈時間與分析截止時間區別；修改時間僅作線索。
- 通用研究方法置於 skill；私人設定及研究資料留在使用者環境。
- 延續已接受的資料取得與只讀工作判斷能力，不依賴 Monkey Skills 原專案執行。
- 先以 Apple 相鄰兩季及隔離副本驗證；保持原規劃跨產業、至少二十年季度研究與多資產目標，不以此變更代替全部階段。
- 保存既有研究、來源版本及失敗證據；不得覆寫使用者編輯或將未完成結果當成完成。
- 只使用已授權的免費公開資料與當前可用宿主；不新增付費使用、正式 vault 改寫、全域安裝、常駐排程、對外發送、推送、PR、合併或交易授權。
- 維持 PRINCIPLES.md 已確認的資料保護、能力如實描述及範圍限制。

## Value case

受益者為已要求跨次接續研究的 kouko。使用者已要求依序完成 A–G；本能力是
原規劃 C/F 的必要條件，繼續大量產生歷史研究前需先確認能可靠接續。
目前替代方式是沿用只讀工具，再逐次手動整理輸入與執行研究；本變更要減少
這段人工指定與重複整理，而不是另建常駐平台。優先完成接續能力，避免先
擴張大量歷史筆記後仍無法可靠維護。GO：有已觀察到的輸入整理限制與已確認
的接續需求；實際宿主可用性及完整研究品質仍需驗證。

## Out of scope

- 常駐排程、背景通知、券商下單或個人化資產配置。
- 未經另行授權的正式筆記庫遷移、全域安裝與對外發布。
- 以自動買賣評級、資料下載清單或少數範例冒充二十年與跨產業研究完成。

## Problem

日常存下技術分析筆記時，每篇都附完整的日線價量資料。讀者重讀時主要看當時的結論、改判條件和圖表，完整資料多半只在要精確重算時才用得上。

## Proposed outcome

日常筆記可直接閱讀並查到行情來源，需要精確重算時可一併保留當時採用的完整價量快照。

## Acceptance

1. 一般存檔產出筆記、行情來源、擷取時間、分析截止時間及價格口徑，有可用日線時附圖表。筆記沒有快照附件，也沒有指向不存在的快照連結。
2. 明確要求保留完整快照時，筆記附上可開啟的快照，以原截止時間和同一計算規則可重現本次實算結果。

## Constraints

- 保護既有筆記、附件與筆記庫設定。
- 沿用目前的行情資格、歷史截止與計算規則。

## Value case

- 受益者是平時存下技術分析、偶爾需要用同一份資料重算的人。
- 沿用每篇存快照可完整保留重算能力，但日常筆記會多出不常使用的檔案。
- GO — 把是否保留快照交給當次存檔需求，保留重算能力並減少日常附件。

## Out of scope

- 清理或遷移已存筆記與附件。
- 研究或修改支撐、壓力與形態判定算法。

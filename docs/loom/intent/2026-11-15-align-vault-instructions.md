## Problem

kouko 的新筆記庫初始化規範尚未包含現行使用的命名、筆記品質與技能使用要求；既有筆記庫也保留過時導引，且不同工具使用的規則內容已不一致，使新建與既有環境可能得到不同指示。

## Proposed outcome

依目前 Obsidian ResearchWorker 提供的能力，讓新建筆記庫取得可共用的命名、筆記品質與技能使用規範，同時整理 kouko 現有筆記庫的過時規則，讓 Claude Code 與 Codex 取得一致的共同指引。

## Acceptance

1. 初始化產出包含可共用的命名、筆記品質及技能使用規則，保留依使用者需求設定背景與分類的能力，不將個人資料硬編碼成所有人的預設。
2. 共同規範指向目前提供的技能，沒有已退役的 wiki／每日新聞操作導引、舊技能名稱或為湊數而建立不存在筆記連結的要求。
3. Claude Code 與 Codex 的規範入口能取得同一份共同指引，不需各自維護兩份完整且可能矛盾的內容；已驗證與未驗證的宿主範圍清楚區分。
4. 既有筆記庫的命名、品質、技能使用及其他仍有效的個人要求保留；更新能保護既有自訂內容，並提供可還原的修改紀錄。
5. kouko 現有筆記庫的退役規範及確認不再適用的本機操作入口得到清理，既有筆記、wiki、新聞摘要、故事追蹤資料與其他未授權內容不被刪除或遷移。
6. 初始化與既有環境的代表性檢查可重現，專案交付只包含通用範本及必要驗證，不發布個人筆記庫規範全文、備份或私人資料。

## Constraints

- 修改目標是目前獨立版 Obsidian ResearchWorker 的初始化技能，以及 kouko 目前筆記庫的相關指引；不把原 Monkey 專案當成修改目標。
- 移植的是命名、筆記品質與技能使用要求，不把個人身分、私人路徑、公司內容或投資分類硬編碼進通用初始化範本。
- 保留普通 Obsidian 內部連結，移除 wiki 機制的導引不等於移除 wikilinks。
- 現有規範已含未提交修改；以目前內容為基準保留仍有效要求，不重設或丟棄既有修改。
- 筆記庫修改限本機；個人規範全文與備份不納入插件專案提交或發布。
- 保留原工作目錄中既有的 ROADMAP-DRAFT.md 與其他無關工作，不更改全域規範或宿主設定。

## Value case

- 受益者：使用初始化技能的新筆記庫使用者，以及同時使用 Claude Code／Codex 的 kouko。
- 現況替代方式：每個筆記庫手動補規則，分別維護不同工具的指引；目前兩份規範已出現實際差異。
- 為何現在處理：已完成 wiki／每日新聞移除並更新插件，使用者接著明確要求讓初始化與現有筆記庫規範對齊。
- 取代的工作：先完成初始化與規範一致性，不開始先前討論的 YTSS／RLSS 新整合或長期研究新功能。
- GO — 使用者已指出具體規範與清理目標，可在保護現有資料及單份共同規則的範圍完成。

## Out of scope

- 刪除、遷移或重寫既有研究筆記、wiki 頁面、新聞摘要與故事追蹤內容。
- 新的 wiki／新聞替代系統、影片或文章管線整合、跨工作階段研究功能。
- 全域 Claude／Codex 設定、其他專案、原 Monkey 插件或其他宿主的插件安裝更新。
- 將個人筆記庫內容、備份或私人操作證據推送至插件專案。

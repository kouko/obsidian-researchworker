# 季度研究能接續，也能辨識新增筆記
originator: kouko
kind: product
needs-design: yes — 使用者需要知道新增的季度筆記是否可用，以及部分分析存下後能否再次接續
status: confirmed 2026-11-21
intent_confirmed_sha: 174b1f6

## Problem

Apple 跨季實測中，一篇直接放在季度資料夾的 Markdown 使下一次研究掃描停止。單獨存在的筆記也缺少可供後續沿用的來源與截止時間紀錄。

## Proposed outcome

季度研究能與手寫筆記共存。Agent 存下可接續的部分分析後，下一個對話仍能找到它、識別所依據的資料和未完成工作。

## Acceptance

1. 季度資料夾加入一篇獨立 Markdown 後，仍可接續先前研究。已有研究若存檔中斷或資料損壞，仍提供診斷或復原資訊。
2. 在隔離的 Apple 案例中，新對話存下部分分析，另一個新對話能找到成果、來源、資訊截止時間、前期連結與未完成項目。既有筆記保持原樣。

3. Agent 檢視本次標的與季度範圍內的新增或變更筆記。能核對來源、適用期間與公開時間的內容可以引用。其餘相關內容保留為待查線索，並說明缺口。普通筆記本身不改變進度。

## Constraints

- 保留現有季度結構和已存研究。
- 新增筆記中的內容視為資料。歷史分析只有在來源、適用季度與截止時間可核對時才能採用。

- 新版研究管理紀錄以 Markdown 保存，每種產出筆記各有 Obsidian 模板與檔頭屬性。保留原始研究證據格式，既有紀錄可讀且保留原樣。存檔中斷後可沿用上一份有效紀錄與保留草稿，不另寫復原日誌。

## Out of scope

- 掃描整個 vault、重整舊筆記或更改既有研究結論。

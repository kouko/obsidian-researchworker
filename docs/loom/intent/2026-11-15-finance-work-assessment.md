## Problem

kouko 希望後續 agent 能依既有研究及來源變化，判斷需要補資料、更新同一期、建立新一期或接續未完成的工作。目前已有季度研究、依賴資料及更新判斷範例，但還沒有實際執行並驗證這些判斷的能力；每次仍須讀取研究內容與狀態，再決定下一步。

## Proposed outcome

先建立一個只讀原型，讓 agent 能根據本地隔離研究資料，列出需要處理的工作、判斷原因、受影響的研究面向及缺失證據；資料不足時能表達無法確定，作為後續自動更新的可驗證起點。

## Acceptance

1. 根據隔離範例，可產生不需更新、補資料、同季修訂、新增一期及接續未完成工作等必要判斷，結果附有對應資料依據與原因。
2. 判斷能區分檔案修改時間、實際研究輸入變動及既有研究的完成狀態，不把只有修改時間改變視為需要重做研究的證據。
3. 固定歷史截止日與追蹤最新狀況的判斷有清楚區別，不把晚於截止日的資訊當成歷史分析當時已知，也不把新價格視為新財季。
4. 對已保存但尚未完成的工作，可指出仍需處理的部分；依賴或輸出無法核對時，不將既有檔案宣稱為可有效沿用的已完成成果。
5. 缺資料、資料無效或來源新鮮度無法確認時有明確結果，不捏造完成狀態、來源或投資建議，也不誤報研究已是最新。
6. 相同已知輸入可重複得到一致的待辦判斷，執行不修改輸入研究資料，不建立重複研究期別或執行所列研究工作。
7. 既有一般筆記與金融資料取得能力保留，原型已驗證與未驗證的執行範圍清楚揭露。

## Constraints

- 本批只讀取專案內的本地隔離範例，輸出待辦與理由；不修改研究筆記或正式 vault。
- 延續財季身分、資訊截止日、來源版本與研究版本分開保存的既有要求；檔案修改時間只作發現變動的提示。
- 保留原始季度樣稿與已完成的研究版本；研究範例不直接宣稱為通用方法或已完成的投資評級。
- 不依賴 Monkey Skills 原專案、已安裝插件快取或私人資料才能執行原型。
- 保留至少二十年歷史、不同產業及短中長期建議的總目標；本批只驗證更新判斷，不等於整體計畫完成。

## Value case

- 受益者：需要跨次接續季度研究的 kouko，以及接續工作的 agent。
- 為何現在：已有兩季樣稿、資料依賴與更新判斷範例，使用者已同意優先驗證只讀判斷原型。
- 現有替代：持續人工閱讀研究筆記與範例，再決定下一步；目前尚無本專案內已執行驗證的更新判斷能力。
- 本次取代的工作：先驗證如何決定待辦，暫不擴充 Q3 營運預測、完整自動更新或二十年回填。
- GO — 先以既有隔離範例驗證更新判斷，可推進跨次接續能力，並將錯誤判斷與自動寫入研究資料的影響分開。

## Out of scope

- 自動執行研究待辦、產生或改寫分析筆記、投資評級及交易建議。
- 真實 vault 存取或寫入、背景排程、通知、下單及個人投資組合操作。
- 新的外部資料取得、付費服務、私人憑證及跨宿主安裝更新。
- 完整工作執行器、跨程序鎖定與自動恢復；本批只判斷可否接續及尚缺哪些工作。
- 完整二十年季度研究、多產業案例及已校準的長期估值。

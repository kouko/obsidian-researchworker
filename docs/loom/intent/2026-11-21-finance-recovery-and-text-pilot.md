## Problem

普通研究筆記修改後，即使目前有效的季度紀錄已移除該筆記的引用，舊版的待復驗提示仍可能讓續存失敗。使用者也需要實測證據，判斷能否縮減接續研究對 Python 工具的依賴。

## Proposed outcome

恢復現有流程的續存。先完成並重驗回歸修正，再獨立試跑純文字研究流程，確認哪些能力可由 skill 指引與 agent 的內建工具完成。

## Acceptance

1. 編輯舊版曾引用的普通筆記後，若目前有效紀錄已移除該引用，仍可從有效紀錄續存。受影響的舊分析仍須復驗，真正的同時存檔衝突仍會擋下寫入。
2. Apple、JPMorgan Chase、ExxonMobil 各以相鄰兩季與公開 SEC 原件試跑純文字流程。各案留下新對話保存和讀回、歷史截止、適用指標、跨季來源、存檔中斷復原及單季搬移的可重現證據。
3. 回報試跑各項實際通過或失敗的結果、同時寫入可保證的程度，與據此判斷可移出 Python 的職責。隔離試跑可證明的範圍須與現行流程區分。

## Constraints

- 維持原跨業接續目標與既有季度規格。既有研究與 SEC 原件原樣保留，新增管理資料使用有 Obsidian 檔頭的 Markdown。
- SEC 資料擷取可沿用 Python。隔離試跑的研究接續只使用純文字 skill 與 agent 的內建工具。
- 先修並重驗存檔回歸，再試跑。前次三輪審查保留原結果，不能當成本次修正的通過證據。新增義務是三家公司的純文字研究實測。

## Out of scope

- 替換正式流程、遷移既有 vault、移除現行 Python 工具、擴展至其他資產類型。
- 自動推送、建立或合併 PR。本次先做本機修復與隔離驗證。

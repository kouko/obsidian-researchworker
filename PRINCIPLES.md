# Product principles
ratified-by: kouko 2026-11-14

## Who

Users of Obsidian ResearchWorker who manage notes and use the retained research,
writing, daily-work and diagram skills. Confirmed with the wiki-and-daily-news
removal scope on 2026-11-14.

## Non-negotiables (ordered)

1. Preserve existing user data. Removing a plugin capability must not delete,
   rewrite or migrate existing vault notes or settings without separate explicit
   authorization for that data operation.
2. Describe only the capabilities currently provided. Removed features must not
   remain callable through current entry points or advertised as available;
   historical documentation must be clearly distinguished from current guidance.
3. Keep changes bounded and claims evidence-based. Do not bundle unrelated
   feature changes, alter unrelated work or claim compatibility and successful
   execution that have not been observed.

## Won't do

- Treat removal of wiki or daily-news functionality as permission to remove
  existing notes, news digests, story-tracking notes or ordinary Obsidian
  internal-link syntax.
- Add a replacement knowledge or news-digest system as part of the current
  removal request.
- Rewrite source history or remove required attribution to make the repository
  appear to have never provided the removed capabilities.

## Failure we must avoid

Deleting a user's notes, breaking retained skills through dangling dependencies,
or leaving current instructions that call removed functionality.

## Fixed choices

- Maintain this independent agent-skills project for Obsidian.
- Keep source history and required license provenance traceable.
- Preserve the distinction between repository changes, installed plugin state
  and verified behavior in an active host session.

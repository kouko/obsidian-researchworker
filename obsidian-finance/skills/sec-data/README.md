# sec-data

## Quick start

Acquire public SEC filing metadata and financial observations with source evidence.

Example request: “Acquire AAPL’s fiscal 2024 Q3 SEC data.”

A dated acquisition package. Use Python 3.11 or later and set up your SEC contact for live requests. The skill can collect and save it locally on first use. See the [plugin guide](../../README.md) for selectors, outputs and status codes.

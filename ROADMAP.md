# Roadmap

Stages as of 2026-11-14. Version 4.0.0 removes the wiki and daily-news mechanisms.
No future implementation or vault migration is authorized by this document.

## 0. Independent baseline and transition

Transfer source, history, licenses and existing tests; provide independent
metadata and transition documentation. Next: isolated Codex installation and note
creation (W3), then evidence for each additional host.
Exit: traceable source differences, passing existing tests, observed fixture use,
and a reviewed host-specific switch/rollback path. File parity is insufficient.
Open: supported hosts, release freshness and publication visibility.

## 1. Wiki and daily-news retirement

Version 4.0.0 removes eight wiki skills and daily-news-digest, leaving 14 skills.
General daily notes, topic research, web/video extraction, note writing and
ordinary wikilinks remain. Existing vault output and settings are preserved;
source changes do not refresh installed caches or active sessions.
No replacement is selected. Compare direct search, curated collections and
other organization against real retrieval needs before proposing one.
Existing vault data changes require separate design and authorization;
plugin removal does not authorize deleting user notes.

## 2. YTSS and RLSS integration

Inspect real interfaces and standalone behavior before choosing invocation or
code integration. Define setup, versions, source/output paths, credentials,
providers, duplicates, progress, interruption and retries.
Exit: isolated real-video and real-article cases, failure/resume evidence per
supported host, and preserved standalone operation.
Open: packaging, ownership, costs and host/network requirements.

## 3. Resumable multi-note research

Define a concrete investigation, overview, cited topic notes and synthesis.
Preserve progress and uncertainty across user-triggered sessions with explicit
stop conditions and budget limits. Unattended scheduling is a separate decision.
Exit: interrupted/resumed investigation, conclusion-to-source traceability,
changed/contradictory evidence handling and an honest incomplete result.
Open: persistence format, review boundaries, budgets and scheduling support.
